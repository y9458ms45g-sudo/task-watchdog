# task-watchdog

任务看门狗：在执行命令行、脚本、构建、测试、安装、部署或数据处理任务时，自动按系统化流程监控任务进度、检测报错并尝试自动修复。

## 核心能力

- **五阶段闭环工作流**：启动预检 → 首次检查 → 持续监控 → 错误诊断修复 → 完成验证
- **自动错误分类**：依赖缺失、路径错误、权限不足、网络问题、配置错误、代码 bug、端口占用
- **修复循环控制**：最多自动重试 3 次，每次必须改变变量，不盲目重试
- **进度监控**：识别正常进行 / 卡住 / 报错三种状态，长任务中间自动简报

## 五阶段工作流

1. **启动预检**：明确成功标志、预估耗时、选择前台/后台执行
2. **首次检查**：启动后立即查看前几行输出，判断是否正常启动
3. **持续监控**：周期性轮询，识别进行中/卡住/报错
4. **错误修复**：读完整报错 → 分类查找修复方案 → 自动修复重试（最多3次）
5. **完成验证**：确认退出码、产物存在、内容非空、关键数据复核

## 适用场景

- 运行预期超过 15 秒的命令或脚本
- 执行 build / compile / test / lint / install / deploy 任务
- 首次运行脚本、不确定环境依赖是否齐全
- 后台任务需要定期检查输出
- 长任务（数据处理、批量操作）需要跟踪进度
